# Aion RU Skill Descriptions

Replaces default client_strings with updated Russian descriptions.

---

## Installation

### Option 1 — Release (recommended)

1. Open the [Releases](../../releases) page  
2. Download the latest `.zip` archive  
3. Extract it into your **Aion game root folder**  
4. Replace files if prompted  

---

### Option 2 — Manual

1. Open the repository  
2. Download `client_strings_skill.xml`, `client_strings_item.xml` and `client_strings_item2.xml` files from the repository root  (use "Download raw file"  for each)  
3. Copy it to: `L10N\7_rus\Data\strings\` folder.
